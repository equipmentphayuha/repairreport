ที่อยู่เว็บไซต์หลักสำหรับสแกน QR Code (Web Base URL)

ระบุลิงก์ที่อยู่เว็บสำหรับสร้างลงบน QR Code เมื่อนำมือถือทั่วไปหรือแอป LINE มาสแกน จะเปิดเข้ามายังลิงก์นี้ทันที

* หากยังไม่ได้อัปขึ้นโฮสต์จริง สามารถปล่อยว่างหรือกด "ใช้ URL ปัจจุบัน" ไว้ก่อนได้ เมื่อย้ายเว็บขึ้นโฮสต์จริง ค่อยมาแก้ไขช่องนี้ได้ตลอดเวลา

➕ เพิ่มช่องกรอกข้อมูลใหม่ (Add New Field)

รายการช่องกรอกข้อมูลทั้งหมดในปัจจุบัน

* ท่านสามารถแก้ไขชื่อ แสดงผล คำอธิบาย หรือลบช่องที่ไม่ต้องการได้
