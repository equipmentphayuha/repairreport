ตั้งค่าผู้ดูแลระบบหลัก (First Admin)

สร้างบัญชีผู้ดูแลระบบคนแรกเพื่อเริ่มบริหารจัดการ

💡 ระบบตรวจพบว่ายังไม่มีบัญชีผู้ดูแลระบบ บัญชีนี้จะได้รับสิทธิ์ Admin ทันทีโดยไม่ต้องรออนุมัติ
👥

จัดการผู้ใช้งานและอนุมัติสมาชิก (Admin Management)

อนุมัติคำขอลงทะเบียน, กำหนดบทบาทสิทธิ์ (RBAC) และเปิด/ปิดการใช้งาน

รายการผู้ใช้งานทั้งหมดในระบบ Cloud Firestore (สามารถดูรหัสผ่าน, แก้ไขชื่อ/อีเมล/สิทธิ์ ได้)
➕

เพิ่มเจ้าหน้าที่ใหม่เข้าระบบ

แก้ไขข้อมูลเจ้าหน้าที่

แอดมินสามารถดูและเปลี่ยนรหัสผ่านให้เจ้าหน้าที่ได้โดยตรง
